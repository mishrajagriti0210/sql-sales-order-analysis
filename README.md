# SQL Sales & Order Analysis

## Project Overview
A SQL mini project analyzing a relational sales database to answer practical business questions about customers, products, orders, and order details.

## Business Objectives
- Understand sales and order performance.
- Analyze customer and product contributions.
- Compare performance across relevant business dimensions.
- Translate query results into concise business observations.

## Database Structure
The project uses four related tables:
- `Customers`
- `Products`
- `Orders`
- `Order_Details`

## SQL Concepts Practiced
- SELECT, WHERE, ORDER BY
- Aggregate functions and GROUP BY
- HAVING and CASE expressions
- INNER JOIN and other table joins
- Subqueries and Common Table Expressions (CTEs)
- Window functions

## Business Questions
The analysis explores customer, product, and order-level performance using joins, aggregations, conditional logic, and analytical SQL patterns. It also includes a completed-orders revenue, cost, and profit analysis.

## Key Learning Outcomes
- Working with related tables in a relational database.
- Choosing appropriate joins and aggregation levels.
- Using CTEs and window functions to structure analytical queries.
- Explaining query findings in business terms.

## How to Use
Open the SQL script in MySQL Workbench or another compatible MySQL environment. Run the database and table creation statements when setting up the project for the first time, then execute the analysis queries. If the database and tables already exist, avoid rerunning the creation statements unless they have been made safe for repeated execution.
